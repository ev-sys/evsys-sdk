`evsys-sdk` is a declarative, modular framework for LLM training experiments.
You describe an experiment in a **single YAML** and the SDK runs it — locally
on TRL or remotely on Tinker — with pluggable algorithms, verifiers, metrics,
data stores, log stores, backends, and inference clients.

```bash
uv pip install -e ".[tinker,local,tensorboard]"
evsys validate config.yaml --deep
evsys run config.yaml
```
