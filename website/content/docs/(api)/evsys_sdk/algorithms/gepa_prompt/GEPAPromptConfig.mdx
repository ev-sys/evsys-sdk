Initial system prompt.

Registry name of the inference client used to evaluate each candidate.

</PyAttribute>

<PyAttribute name={"task_lm_config"} type={"dict[str, Any]"} value={"Field(default_factory=dict)"} />

<PyAttribute name={"reflection_lm"} type={"str | None"} value={"None"}>

Optional inference client used to propose mutated prompts; required for
the real gepa path. Without it we fall back to the built-in mutator.

</PyAttribute>

<PyAttribute name={"reflection_lm_config"} type={"dict[str, Any]"} value={"Field(default_factory=dict)"} />

<PyAttribute name={"population_size"} type={"int"} value={"4"} />

How many PromptExamples to evaluate each candidate on (per iteration).

</PyAttribute>

<PyAttribute name={"use_gepa_lib"} type={"bool"} value={"True"}>

If True and the `gepa` package is importable, delegate to it.

</PyAttribute>
