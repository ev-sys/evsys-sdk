title: DataStore
---

Abstract data sink+source.

Implementations:
  * ``LocalDataStore`` — filesystem JSONL/parquet/json, no network.
  * ``SupabaseDataStore`` — REST against PostgREST tables.
  * ``InMemoryDataStore`` — for tests.
