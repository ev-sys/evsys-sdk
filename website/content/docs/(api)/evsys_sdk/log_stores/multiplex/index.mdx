MultiplexLogStore — fan out to several log stores at once.

Useful for ``log_store.kind: multiplex`` configs:

    log_store:
      kind: multiplex
      params:
        children:
          - kind: jsonl
            params: \{ log_dir: ./logs \}
          - kind: tensorboard
            params: \{ log_dir: ./tb \}
