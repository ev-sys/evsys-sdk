```python
def compute(self, task_rewards: Sequence[Sequence[float]]) -> float:
    passes = sum(1 for rs in task_rewards for r in rs if _passes(r))
    total = sum(len(rs) for rs in task_rewards)
    return passes / total if total else 0.0
```
