```python
def compute(self, task_rewards: Sequence[Sequence[float]]) -> float:
    tasks = _nonempty(task_rewards)
    if not tasks:
        return 0.0
    solved = sum(1 for rs in tasks if all(_passes(r) for r in rs[: self.k]))
    return solved / len(tasks)
```
