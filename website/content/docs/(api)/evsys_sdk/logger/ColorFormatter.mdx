<PyFunction name={"format"} type={"(self, record)"}>

<PySourceCode >

```python
def format(self, record):
    message = super().format(record)
    if self.use_color:
        color = self.COLORS.get(record.levelno, "")
        if color:
            message = f"{color}{message}{RESET}"
    return message
```
